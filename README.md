# Auralis Audio

Audio & object design · Independent concept demo

A turntable concept that loads a record from its sleeve and settles into a listening ritual.

**[Visit the live site ↗](https://northlight7.github.io/cinematic-auralis/)** · [Project notes & screenshots](https://github.com/northlight7/web-design-portfolio/tree/main/projects/auralis) · [Full portfolio](https://northlight7.github.io/web-design-portfolio/)

## What to try

Scroll to the ritual, choose a finish, then drop the needle and watch the transport start.

## Design focus

The record travels from jacket to spindle before the tonearm settles. Finish choices drive the plinth material, and the transport readout keeps time while the record turns. Native pointers only: there is no custom cursor. Motion can be paused from the navigation, and the page keeps its content and controls when motion is off.

## Run locally

This is a buildless static site. Serve this repository with a static HTTP server, for example:

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser. Fonts, dependencies and all visual assets are hosted locally with the site. Nothing is fetched from a third-party runtime.
